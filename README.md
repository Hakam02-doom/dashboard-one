# Uplift AI dashboard — first draft

A browser-ready recreation of the supplied dashboard reference, adapted to Uplift AI's SEO campaigns, AI-search visibility, content publishing, and traffic reporting.

Open `dist/index.html` directly, or serve `dist` with any static web server. No build or package installation is required.

Includes responsive layouts, chart entrance animations, reduced-motion support, campaign search and details, session-only campaign creation, CSV report downloads, a share-link dialog, and a locally saved appearance preference.

All metrics and team members are illustrative. No analytics, publishing, or account integrations are connected. Campaign additions reset on reload. Google Fonts and demo portraits load from external services; fallback fonts are built in.

Reference: supplied dashboard screenshot. Product context: https://www.upliftai.co/.
